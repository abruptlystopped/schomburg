# Phase 1 Alpha

Schomburg is a local-first evidence engine. **Schomburg does not ask users to document their work. It preserves factual evidence produced by the tools they already use.**

Phase 1 proves discovery, explicit consent, persistent connections, factual collection, SQLite preservation, and a combined timeline. Git is the only production connector. Discovery is not collection; consent is required before collection. Connectors own source-specific collection and factual presentation; the engine remains source-agnostic. Context, filters, learning, and interpretation are separate future layers.

The CLI is a temporary alpha interface. Phase 2 is Presentation: making preserved evidence usable without terminal commands.
