# Schomburg

> Preserve and organize the evidence of engineering work.

Schomburg is a local-first engineering record.

It passively collects evidence from your development workflow and preserves it as a chronological record.

Not documentation.

Not project management.

Not an AI coding assistant.

Just the engineering record.

## Vision

Software projects have history.

That history is scattered across Git commits, AI conversations, terminal sessions, editor activity, builds, tests, and deployments.

Schomburg brings those pieces together into a single evidence-backed record of what happened.

## Principles

### Local First

Your engineering history belongs to you.

Everything is stored locally by default.

### Passive

Never asks you to document your work.

Schomburg quietly observes the evidence already being created.

### Evidence-Based

Every entry originates from evidence.

Examples include:

- Git
- GitHub
- VS Code
- Terminal
- ChatGPT
- Claude
- Codex
- Build systems
- Test results

### Preserve, Don't Interpret

Schomburg's responsibility is to preserve and organize the engineering record.

Interpretation belongs to the developer.
